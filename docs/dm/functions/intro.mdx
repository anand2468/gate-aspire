In mathematics, a function is a relation between sets that associates to every element of first set
exactly one element of the second set
- a relation $$f$$ from set $$A$$ to a set $$B$$ is called function,  if each element of $$A$$
is mapped with a unique element on $$B$$.


$$
f:A\to B
$$

- range of function $\subset B $
- range of $$f = \{y \mid y \in \mathbb{B} , (x,y) \in f \}$$
