> **throughput** <br/>
> it means the number of jobs completed for unit time is called throughput of a system

- If one job is finished completely then only another job will be scheduled into CPU
- Increased cpu idleness
- Decreased throughput of the systems
- ex: IBM os 2

## 2. Multi-Programming OS

<ImageCarousel
  images={[
    '/img/os/multi-programming-1.png',
    '/img/os/multi-programming-2.png',
    '/img/os/multi-programming-3.png',
  ]}
/>

- if job is leaving the CPU then the another job which is ready for execution will be scheduled on to the CPU
- Increased CPU utilization
- increased throughput of the system
- ex: windows, unix, linus.

## Multi-Taksing

![multi-tasking os imgae](/img/multi_tasking_os.png)

- Multitasking is an extension of multi-programming OS
- the jobs will be executed in the time shared mode
- ex: windows, unix, linux

## Multi processor OS

![multi-processor os image](/img/os/multi_processor_os.png)

- Increased throughput of the system
- **reliability:** if one cpu is failed the system will still run with the help of remaining CPU's (fault tolarant systems)
- thsese systems are Economical
- ex: unix

## Realtime OS
